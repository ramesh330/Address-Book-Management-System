# Addressbook Management System

A console-based Address Book Management System developed in C. This application allows users to manage contacts
efficiently using file handling and structures.

## Features

- Add Contact
- Search Contact
- Edit Contact
- Delete Contact
- Display Contacts
- Save Contacts to CSV File
- Sort Contacts
  - By Name
  - By Mobile Number
  - By Email
- Loading Animation
- Input Validation

## Technologies Used

- C Programming
- Structures
- File Handling
- String Handling
- Git
- GitHub
